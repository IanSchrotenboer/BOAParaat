# Boa Paraat 1.13.8

Synchroniseren werkt weer op elk apparaat.

## Opgelost

- **"Bijwerken lukt nu niet":** op een apparaat waar je was ingelogd zonder de tweede stap (de code uit je authenticator-app), weigerde de database je voortgang. De app gaf dan ten onrechte de melding over je internetverbinding. Nu vraagt de app op zo'n apparaat om de code uit je authenticator-app, onder Profiel → Account. Daarna wordt je voortgang weer bewaard.
- **Duidelijke meldingen:** gaat synchroniseren mis, dan zegt de app waarom. Dat kan zijn: geen internet, de tweede stap nog niet bevestigd, je inlogsessie is verlopen, of de server is even niet bereikbaar.
- **Al bezig:** tik je op "Nu synchroniseren" terwijl er al gesynchroniseerd wordt, dan krijg je geen foutmelding meer.

## Installeren

Download `Boa-Paraat.apk` hieronder en installeer hem over je huidige versie heen. Je voortgang blijft bewaard.

`Boa-Paraat.aab` is voor de Google Play Store.
